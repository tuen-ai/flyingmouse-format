# 飞鼠格式 · 离线单文件工具（offline/）

一个**不用安装、不用联网、不用服务端**的网页版转换台：把 `offline/dist/flyingmouse-format-offline.html`
拷到任何一台电脑，双击用浏览器打开就能转文件。所有解码、转换、打包都在浏览器里完成，文件不会离开本机。

它**不是**桌面版的替代品，而是桌面版装不上时的补充：需要 FFmpeg / LibreOffice / Poppler / Tesseract /
docengine 的能力（音视频、Office、PDF 解析、OCR）仍然只有桌面版有。

## 1. 交付物

| 路径 | 作用 |
| --- | --- |
| `offline/dist/flyingmouse-format-offline.html` | 构建产物，唯一需要分发的文件（约 450 KB，含内联鼠鼠状态图） |
| `offline/index.html` / `offline/styles.css` | 页面结构与重做后的 UI |
| `offline/core/*.js` | 与浏览器无关的纯逻辑（Node 与浏览器双用，测试直接 require） |
| `offline/app/*.js` | 浏览器侧：文案、Canvas 图片管线、控制器 |
| `scripts/build-offline.js` | 内联打包成单文件；`--check` 校验产物与源码一致 |
| `scripts/png-mini.js` | 只用 `node:zlib` 的 PNG 解码 / 缩放 / 重编码（把 195 KB 的鼠鼠图缩到 25 KB 再内联） |

构建与自检：

```bash
node scripts/build-offline.js          # 重新生成单文件（改了 offline/ 就必须重跑）
node scripts/build-offline.js --check  # 校验已提交产物与源码一致
npm run build:offline                  # 同上（package.json 脚本）
node --test tests/offline-core.test.js tests/offline-build.test.js tests/offline-ui-static.test.js
```

构建是**可复现**的：同样的源码产出同样的字节（ZIP 用固定 1980-01-01 时间戳、不写构建时间），
所以 `tests/offline-build.test.js` 能直接按字节比对已提交产物。

## 2. 能力范围

目标格式取**所有已选文件的交集**（与桌面版同一条产品约定）。

| 源 | 可转目标 | 实现 |
| --- | --- | --- |
| PNG / JPG / WebP / GIF / BMP / ICO / SVG / AVIF | PNG、JPG、WebP、BMP、ICO、PDF、ZIP | 浏览器解码 + Canvas 编码；BMP / ICO 由 `core/image-codecs.js` 自己写字节；PDF 由 `core/pdf-writer.js` 内嵌 JPEG（DCTDecode） |
| TXT / MD / HTML / LOG | TXT、MD、HTML、CSV、EPUB、DOCX、ZIP | `core/text-formats.js` + `core/ebook.js` + `core/office.js` |
| CSV / TSV | CSV、TSV、JSON、MD、HTML、TXT、DOCX、EPUB、ZIP | 严格 CSV 语法（BOM、`""` 转义、字段内换行、列数必须一致） |
| JSON | JSON、CSV、MD、TXT、ZIP | 键路径扁平化 + 排序，所有字段加引号 |
| XML | JSON、TXT、ZIP | 直接复用仓库根目录的 `xml-json.js`（零依赖，已有测试覆盖） |
| 任何其它文件 | ZIP | 整个队列打成一个压缩包 |

其它能力：

- 多张图片按队列顺序**合并成一个 PDF**（可上下移动排序，可选 A4 / Letter / 跟随图片、页边距）。
- 图片质量、最大边长、透明背景填充（白 / 黑）；JPG / BMP / PDF 目标会按所选背景合成透明像素。
- CSV 分隔符（逗号 / 分号 / Tab）与 UTF-8 BOM 开关；电子书标题。
- 文本文件按 UTF-8 读取，解出替换字符时自动回退 GBK（中文 Windows 的 Excel 导出常见）。
- 结果区「保存」（直接下载）与「另存为…」（支持的浏览器用文件选择器，可自选目录、不会被浏览器改名）。
- 多结果时可「打包下载 ZIP」。

## 3. 与桌面版共用的约定

- **鼠鼠品牌**：页面必须有 `#mouseMascot`，状态覆盖 upload / analyzing / converting / batch / success / error / idle，
  状态图由 `public/assets/mouse-format/mouse-*.png` 缩放后内联，`data-state` 与桌面版一致。
- **文案**：`offline/app/messages.js` 是扁平的 `zh-CN` / `en-US` 字典，键名沿用 `domain.item`，
  由 `public/i18n.js` 的 `createI18n` 消费，语言键仍是 `flyingmouse.language.v1`。
- **目标格式记忆**：复用 `public/conversion-preferences.js`（`flyingmouse.conversionPreferences.v1`），
  离线版新增的主题键是 `flyingmouse.theme.v1`。
- **禁止动态 `innerHTML`**：所有用户文本走 `createTextElement` / `textContent` / `replaceChildren`。
- **转换语义**：CSV / JSON / Markdown / HTML / EPUB 的规则按 `text-conversion.js`、`text-docx.js`、`ebook.js`
  的既有契约重写，错误码沿用 `CSV_PARSE_FAILED`、`JSON_CSV_PATH_COLLISION`、`XML_JSON_PARSE_FAILED`、
  `BMP_UNSUPPORTED_VARIANT`、`ICO_UNSUPPORTED_VARIANT`，非致命提示沿用 `TEXT_JSON_WRAPPED` 等 `{code, messages:{zhCN,enUS}}` 结构。

## 4. UI 重做要点

在保留鼠鼠品牌（珊瑚红 `#e95f6d` + 墨线描边 + 硬阴影）的前提下重排了信息结构：

- 顶栏：品牌圆形「舱口」+ 离线徽标 + 主题切换（跟随系统 / 浅色 / 深色）+ 语言。
- 上传台：整块可点击的投放区，鼠鼠随状态换图，支持拖拽 / 点击 / `Ctrl+V` 粘贴，下方是三条离线承诺。
- 工作台：左侧队列卡（缩略图、体积、状态、排序、移除），右侧「转换设置」控制台（chip 式目标格式 + 按目标显示的选项）。
- 结果卡：逐个保存 / 另存为，多结果时打包下载。
- 深浅双主题、`prefers-reduced-motion` 降级、980 / 860 / 560 三档断点、`:focus-visible` 焦点环、
  `role="status"` 的状态行、跳转到上传区的 skip link。

## 5. 限制（写清楚，别让用户误会）

- 音频、视频、Office（doc/xls/ppt）、PDF 解析、OCR **不支持**——这些必须有本地引擎，请用桌面版。
- DOCX 是最小实现：标题、段落、列表（以字符标记呈现）、表格；不含图片、页眉页脚、编号样式。
- EPUB 章节切分与桌面版一致（md 按标题、其它按 2000 字聚合，最多 99 章）。
- Markdown ↔ HTML 是自写的轻量实现（桌面版用 marked / turndown）：常见语法一致，极端排版可能有差异。
- 图片解码依赖浏览器：SVG / AVIF / ICO 的支持度随浏览器而定，BMP 解不开时会回退到内置 BMP 解码器。
- 单个文件上限 256 MB，图片像素上限 5000 万（与桌面版资源上限口径一致）。
- 浏览器内存有限，超大批量请分批。

## 6. 验收记录（2026-08-18）

- `node --test tests/offline-core.test.js tests/offline-build.test.js tests/offline-ui-static.test.js`：31 项全绿。
- 真实 Chromium（`/opt/pw-browsers/chromium`，file:// 打开单文件）端到端跑通：
  PNG→WebP / PDF / ICO / BMP、CSV→JSON / DOCX、MD→EPUB / HTML、混合队列→ZIP、拖拽中文文件名→JSON；
  控制台零报错，**零外部请求**（只出现 file:// 与 blob:）。
- 浏览器产物用仓库自带解析器交叉校验：ICO 用 `ico-format.js`、BMP 用 `bmp-input.js`、
  EPUB/DOCX/ZIP 用 zip 结构校验（`mimetype` 必须是第一个且不压缩）、PDF 校验 xref 偏移与内嵌 JPEG。
- 未在真实 Windows / macOS 桌面浏览器上人工验收；Firefox / Safari 没有 `showSaveFilePicker`，会自动回退到普通下载。
